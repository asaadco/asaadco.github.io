## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | CSS Variable | Usage |
|-------|-------|--------------|-------|
| xs | 4px | `--space-xs` | Icon gaps, tight inline padding |
| sm | 8px | `--space-sm` | Compact element gaps (e.g. nav link padding inline) |
| md | 16px | `--space-md` | Default element spacing, form field gaps |
| lg | 24px | `--space-lg` | Within-component padding, timeline entry inner padding |
| xl | 32px | `--space-xl` | Between-component gaps, timeline dot spacing |
| 2xl | 48px | `--space-2xl` | Section vertical padding (top/bottom) on mobile |
| 3xl | 64px | `--space-3xl` | Section vertical padding (top/bottom) on desktop |

Exceptions:
- Nav height: 60px (not a multiple of 4 — chosen to satisfy 48px minimum touch target with comfortable visual padding)
- Touch targets on interactive elements (nav links, future): 44px minimum height per WCAG 2.5.5
- Hero section vertical padding: 96px on desktop — declared as a component-level property on `<Hero />`, not a scale token (96 = 4 × 24, valid grid multiple; 64px produces cramped hero at ≥1024px)

**Source:** 8-point scale default, confirmed against CONTEXT.md spacing discretion and WCAG touch target requirements.

## Typography

| Role | Font | Size | Weight | Line Height | CSS Variable Reference |
|------|------|------|--------|-------------|------------------------|
| Body | Inter Variable | 16px | 400 (regular) | 1.6 | `var(--font-body)` |
| Label / Nav | Inter Variable | 14px | 400 (regular) | 1.4 | `var(--font-body)` |
| Section Heading | Playfair Display | 28px | 700 (bold) | 1.2 | `var(--font-display)` |
| Display / Hero Name | Playfair Display | clamp(36px, 6vw, 56px) | 700 (bold) | 1.1 | `var(--font-display)` |

Notes:
- Body line height is 1.6 (slightly above standard 1.5) — longer paragraphs in About narrative benefit from extra leading.
- Two font weights only: 400 for all body/prose/labels, 700 for all headings, display, and role titles. No exceptions.
- The Hero display size clamps from 36px (mobile, 375px) to 56px (desktop, ≥768px) via `clamp(36px, 6vw, 56px)`.
- Tagline / professional identity under the name: 28px, weight 700, Playfair Display — provides adequate hierarchy below the 56px name.
- Timeline role title: 16px, weight 700, Inter Variable — weight alone differentiates role titles from body text at the same size.
- Timeline org / date: 14px, weight 400, Inter Variable.

**Source:** CLAUDE.md typography section, CONTEXT.md (no explicit overrides on scale — Claude's discretion applied). Revised per checker: 4 sizes only (14px, 16px, 28px, clamp display), 2 weights only (400, 700).

## Color

| Role | Value | CSS Variable | Usage |
|------|-------|--------------|-------|
| Dominant (60%) | `#0d1b2a` | `--color-bg` | Page background, hero section |
| Dominant dark | `#070d14` | `--color-bg-deep` | Hero gradient end stop (darker tone) |
| Secondary (30%) | `#1a2a3a` | `--color-surface` | Nav background, timeline entry cards, footer |
| Text primary | `#f5f5f5` | `--color-text` | All body copy and headings on dark surfaces |
| Text muted | `#9baab8` | `--color-text-muted` | Timeline org, date, secondary meta |
| Accent (10%) | `#d4a017` | `--color-accent` | Timeline dots, nav link hover underline, decorative dividers |
| Accent hover | `#e8b520` | `--color-accent-hover` | Nav link active/hover state, timeline dot hover |
| Destructive | n/a | — | No destructive actions in Phase 2 |

**Hero gradient:** `linear-gradient(160deg, #0d1b2a 0%, #070d14 100%)` — deep navy to near-black. Direction 160deg gives a subtle diagonal that avoids a flat look.

**Nav surface:** `#1a2a3a` at 95% opacity with `backdrop-filter: blur(8px)` when the page is scrolled beyond the hero (applies a subtle glass effect). This is within Claude's discretion — improves legibility when nav overlaps body content.

**60/30/10 split:**
- 60% dominant: page background and hero fill.
- 30% secondary: nav bar, timeline entry background cards, footer strip.
- 10% accent: timeline dots, nav hover underlines, any decorative horizontal rules.

Accent reserved for: timeline entry dots, nav anchor link hover/active underline, section heading decorative underline, and no other elements.

**WCAG AA compliance:** `#f5f5f5` on `#0d1b2a` yields contrast ratio ~15:1 (far exceeds 4.5:1 AA). `#d4a017` on `#0d1b2a` yields ~5.2:1 (passes AA for normal text). Muted text `#9baab8` on `#0d1b2a` yields ~4.6:1 (passes AA).

**Source:** CONTEXT.md D-03, D-05, Specifics section (hex range guidance). Values selected by Claude within stated direction.

## Component Contracts

### Nav (`<Nav />`)

- Position: `position: sticky; top: 0; z-index: 100`
- Height: 60px
- Layout: flex row, space-between. Logo/name on left, anchor links on right.
- Logo text: "Asaad" — Inter Variable, 16px, weight 700, color `--color-text`
- Nav links: Inter Variable, 14px, weight 400, color `--color-text`, uppercase letter-spacing 0.05em
- Links: About (`#hero`), Journey (`#journey`), Values (`href="#"` — dead link until Phase 3), Contact (`href="#"` — dead link until Phase 4)
- Hover state: gold underline, color transitions to `--color-accent-hover`. Transition: `color 150ms ease, border-color 150ms ease`
- Background: `--color-surface` with `backdrop-filter: blur(8px)`. No JS scroll listener required — CSS sticky behavior handles positioning.
- Mobile (≤768px): same sticky bar, links stack or shrink. Full hamburger menu is Phase 3 scope — in Phase 2 the nav links remain visible and wrap if needed.
- No `client:*` directive — purely static.

### Hero (`<Hero />`)

- Section ID: `id="hero"`
- Height: `min-height: 100vh`
- Background: `linear-gradient(160deg, var(--color-bg) 0%, var(--color-bg-deep) 100%)`
- Layout: flex column, centered (both axes), text-align center
- Padding: `96px` top/bottom on desktop (hero-only — not a scale token), `--space-3xl` (64px) on mobile. Left/right: `--space-md` minimum.
- Name: Playfair Display, `clamp(36px, 6vw, 56px)`, weight 700, color `--color-text`, line-height 1.1
- Professional tagline (1 sentence): Playfair Display, 28px, weight 700, color `--color-text-muted`, margin-top `--space-md`
- About narrative (2–3 paragraphs): Inter Variable, 16px, weight 400, line-height 1.6, color `--color-text`, max-width 640px, margin: 0 auto, margin-top `--space-xl`
- About paragraph spacing: `--space-md` between paragraphs
- No scroll-down indicator in Phase 2 (deferred to polish phase)
- No `client:*` directive.

### Journey (`<Journey />`)

- Section ID: `id="journey"`
- Background: transparent (inherits page `--color-bg`)
- Section heading: Playfair Display, 28px, weight 700, color `--color-text`, text-align center, with a 2px `--color-accent` decorative underline (40px wide, centered, margin-top `--space-xs`)
- Padding: `--space-3xl` top/bottom on desktop, `--space-2xl` on mobile
- Entries: 5–7 placeholder entries (Lorem-style content per D-14)

**Desktop layout (≥768px):** Center-stem. A 2px vertical line (`--color-surface` or `--color-accent` at 30% opacity) runs the full height of the section, centered. Entries alternate left/right sides. Each entry's dot sits on the center stem.

**Mobile layout (<768px):** Single-column, left-aligned. Vertical line on the left edge (16px indent from viewport). All entries stack in chronological order, full width.

**Timeline breakpoint:** 768px — below this, switches from center-stem to single-column.

**Timeline entry structure:**
- Dot: 12px circle, background `--color-accent`, border: 2px solid `--color-bg`, centered on the stem
- Card: `--color-surface` background, border-radius 8px, padding `--space-lg`
- Role: Inter Variable, 16px, weight 700, color `--color-text`
- Organization: Inter Variable, 14px, weight 400, color `--color-accent`
- Time period: Inter Variable, 14px, weight 400, color `--color-text-muted`
- Impact statement: Inter Variable, 16px, weight 400, line-height 1.6, color `--color-text`, margin-top `--space-sm`
- Card max-width: 440px on desktop (each side). Full width on mobile.

**Source:** CONTEXT.md D-11, D-12, D-13, D-14 (all locked decisions).

### Footer (`<Footer />`)

- Background: `--color-surface`
- Height: auto, padding `--space-lg` top/bottom
- Content: "© 2026 Asaad" — Inter Variable, 14px, weight 400, color `--color-text-muted`, text-align center
- No social links, no email, no nav (D-15 — locked).

## Interaction Contracts

### Smooth Scrolling

- Declared in `global.css`: `html { scroll-behavior: smooth; }`
- No JS required. (CONTEXT.md D-10 — locked.)
- `scroll-padding-top: 60px` on `html` to offset the sticky nav height when anchor targets are jumped to.

### Nav Anchor Links

- `#hero` — scrolls to top of Hero section
- `#journey` — scrolls to Journey section
- Values / Contact — `href="#"` placeholder. Must have `aria-disabled="true"` and `tabindex="-1"` so keyboard users are not trapped on non-functional links.

### No JS in Phase 2

All components in Phase 2 are purely static. No `client:load`, `client:idle`, or `client:visible` directives. No vanilla JS files added in this phase. Sticky nav via CSS only.
